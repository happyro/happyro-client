# 2026-09-07

## Added

- 点击右上角小地图任意位置可直接打开当前地图的导航窗口。
- 导航搜索新增地图类型，支持按中文地图名和资源地图 ID 搜索。
- 导航地图选点后可开始或停止自动寻路，跨地图时会在切图后继续规划。
- 导航传送入口改为使用服务器下发的权限、跨地图和冷却配置，并在冷却期间禁用重复操作。
- 左上角工具栏新增可扩展的“冒险工具”窗口，首个标签提供所有玩家可浏览的魔物图鉴、中文与资源名搜索、分类、分页、详情和掉落资料。
- 魔物图鉴使用从已核验后台快照生成的独立目录与 WebP 图集；获得服务器权限的玩家可请求在当前角色旁召唤魔物，并看到冷却和失败原因。

## Fixed

- 魔物详情的召唤操作栏固定贴合窗口底边，掉落列表独立滚动，不再从操作栏下方露出内容。
- 魔物图鉴的普通掉落和 MVP 奖励改为显示 Renewal 物品资料中的中文名称，并保留英文名作为悬停提示。
- 修复 Renewal 任务窗口所有任务列表被默认样式隐藏，以及竖排标签文字重叠，导致新角色接取任务后无法正常查看“进行中”等分类的问题。
