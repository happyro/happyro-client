# 移动端认证与屏幕方向

手机和平板的登录、选角和创建角色页面使用 `UI/Mobile/` 组件，通过移动端 bootstrap 注册，复用公共角色业务逻辑。页面按可用宽高调整排列，旋转不重新挂载组件，因此保留输入、角色选择和外观设置。软键盘使用 `visualViewport` 调整面板位置与高度，长内容在面板内原生滚动。

点击进入游戏时才启用横屏要求。竖屏下先显示提示，旋转后发送选角请求；等待期间可返回选角，连接中断会取消待执行请求。进入游戏后转回竖屏会显示遮罩并阻止操作，但不暂停游戏、不关闭连接。返回登录、选角或进入失败后解除方向限制。此约束由页面遮罩实现，不依赖浏览器的屏幕方向锁定 API。

设备方向取自屏幕方向信息，软键盘引起的视口缩小不会被当成旋转。PWA 游戏入口在启动时声明设备视口，移动端对页面内容启用尺寸与绘制隔离，防止旧游戏画布在旋转后撑大布局视口。

验证包括移动端认证组件、键盘可视区域、方向判断和横屏门禁测试；浏览器需检查横竖屏布局、原生滚动、输入状态保留、竖屏进入/取消、横屏继续、游戏中旋转及返回选角。iOS 软键盘行为仍需真机验收。
