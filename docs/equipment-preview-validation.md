# 装备与选角外观修复验收

日期：2026-09-20。状态：实现完成，抽样验收通过。

## 原因与改动

- Lua `AccNameTable`、`RobeNameTable`、`JobNameTable` 是资源文件名；按用户字符集解码会产生与 GRF 字节路径不一致的名称。改为保留字节，显示用随机属性文本仍按用户字符集解码。
- 装备、换装、物品外观预览及查看他人装备复用外观不变的实体，避免逐帧创建或设置实体；角色类在首次绘制时读取，避免循环依赖初始化顺序导致空白。
- 一般装备预览按实际装备部位 `equipped` 读取外观，不使用可装备部位 `location`。
- 角色列表按槽位更新，重复分片不再追加重复角色，已有槽位复用实体。
